# App access — ALTO EFECT 1.1

## Apakah semua fungsi tersedia tanpa akses khusus?

**Ya.** Tidak ada akun, login, langganan, kode undangan, atau konten terkunci.
Semua efek, preset pabrik, dan pengaturan dapat dibuka tanpa kredensial.

## Izin mikrofon

- Mikrofon diperlukan hanya saat pengguna menekan **POWER** untuk menjalankan
  mesin audio.
- Sebelum izin sistem diminta, aplikasi menampilkan dialog penjelasan
  (prominent disclosure): audio hanya untuk input gitar real-time, diproses di
  perangkat, tidak direkam/diunggah, dan aplikasi tidak memiliki izin INTERNET.
- Jika pengguna menolak, UI tetap dapat dibuka dan preset tetap dapat dilihat;
  audio tidak berjalan.

## Instruksi untuk reviewer Play

1. Pasang AAB/APK di perangkat Android 7.0+.
2. Buka aplikasi. Layar pedalboard akan tampil.
3. Tekan **POWER**.
4. Pada dialog **Microphone access**, tekan **Continue**.
5. Setujui izin mikrofon Android.
6. Jika muncul peringatan headphone, sambungkan headset atau tekan **Start anyway**
   dengan volume rendah.
7. Pilih preset dari tab **Presets**, aktifkan pedal, dan putar potensiometer.
8. Buka **Audio Setup** untuk memilih perangkat input/output.

Tidak ada kredensial uji yang diperlukan.

## Catatan perangkat

- Headset atau antarmuka audio USB disarankan untuk menghindari feedback.
- Tanpa headset, aplikasi tetap berjalan tetapi dapat menimbulkan feedback;
  gunakan volume rendah.
