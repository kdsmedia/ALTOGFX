# Graphics — ALTO EFECT 1.0

## File

| File | Ukuran | Format | Dipakai untuk |
|---|---|---|---|
| `icon-512.png` | 512×512 | PNG 32-bit RGBA | App icon Play Store |
| `feature-graphic-1024x500.png` | 1024×500 | PNG RGB (tanpa alpha) | Feature graphic |
| `feature-graphic-1024x500.jpg` | 1024×500 | JPEG RGB | Alternatif feature graphic |

## Sumber

- `icon-512.png` berasal dari `app/src/main/ic_launcher-playstore.png` dan
  memakai artwork `Logo.png`.
- Feature graphic dibuat dari `Altomedia.png` (latar panggung) dan ikon aplikasi.
  Teks: **ALTO EFECT — GUITAR MULTI-EFFECTS — 9 PEDALS • 8 PRESETS • 100% OFFLINE**.

## Aturan Play Store

- Icon: tepat 512×512 px, PNG 32-bit, tidak boleh memiliki sudut membulat yang
  dipaksakan (Play yang memberi mask).
- Feature graphic: tepat 1024×500 px, PNG/JPEG, **tanpa transparansi**.
- Jangan menambahkan teks penting di tepi gambar; Play dapat memotong bagian
  tertentu pada tampilan tertentu.
- Screenshot bukan bagian dari folder ini; ambil dari aplikasi asli.

## Mengganti

Jika ingin mengganti feature graphic, pertahankan rasio 1024:500, hindari alpha,
dan gunakan warna gelap + aksen biru/oranye agar konsisten dengan aplikasi.
