# ALTOGFX — Audio Effects Processor for Android

<a href='https://play.google.com/store/apps/details?id=com.altomedia.altogfx'><img width=150 alt='Get it on Google Play' src='https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png'/></a>

ALTOGFX is a real-time guitar and voice effects processor for Android. It is a LADSPA / LV2 plugin host with a low latency native audio engine. More than 200 high quality plugins are included, and you can arrange them in any order to build your own tone.

***

### Features

* High quality plugins: distortion, overdrive, cabinet emulation, delay, echo, reverb, chorus, flanger, phaser, compressor, limiter, sustain, vocoder, tube emulators and more
* Neural Amp Modeler and AIDA-X model support
* IR cabinet loader with convolution reverb
* Easy to use UI with customizable background and themes
* One tap to add an effect to the chain, or load a ready made preset
* Unlimited effects in any order in the effect chain
* Customize effect parameters to match your sound
* Save presets and share them
* MIDI control support
* Supports built-in mic, headset mic and USB audio interfaces
* High performance low latency native audio processing
* High quality floating point precision audio processing
